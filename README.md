观势将行情同步、数据校验、参数寻优和回测整合为一键研究流程。支持趋势回调（SMA）与 Martin Luk 日线量化版，使用相同数据和账户口径对比策略，并保留快照、参数、成交明细与历史结果。

**面向本地研究，不连接券商、不执行真实交易。** 日线成交是明确假设下的模拟，样本内最优参数与历史收益不代表未来表现。

## 主要功能

- **一键研究**：更新行情 → 补齐与校验 → 参数寻优 → 自动回测，支持进度查看、终止、任务复用和按标的排队。
- **多策略比较**：SMA、Martin 日线版与买入持有基准，查看收益、回撤、净值、成交与费用。
- **短历史适配**：缩小可行参数网格，跳过历史不足的策略，保留预热和数据校验要求。
- **交互图表**：日／月／年 K 线、前复权／未复权切换、均线、指数对比、日期定位、缩放与平移。
- **区间账户收益**：图表查看范围与策略区间收益联动，明确区分配置范围、预热范围和实际回测范围。
- **数据可追溯**：原始响应归档、不可变数据快照、公司行动证据、历史回测和 CSV 导出。
- **股票池研究**：成员有效期、结构止损、风险定仓、相对强度对照及逐笔诊断。
- **桌面与手机**：自定义日期选择器、密集成交标记避让、完整百分比与股价展示；最近选择保存在当前浏览器。

## 快速开始

### 环境要求

- Python **3.11+**
- [uv](https://docs.astral.sh/uv/) Python 环境与依赖管理工具
- Node.js **20.19+ 或 22.12+**，以及 npm
- 首次安装与行情更新需要网络；读取已保存结果不需要行情源在线

启动脚本使用 Unix 命令及进程管理方式，当前主要在 **macOS** 本地验证；Windows 原生启动未验证。

```sh
git clone https://github.com/W1tFzQq08pTv/pullback-lab.git
cd pullback-lab
./start.sh
```

首次运行会根据 `uv.lock` 和 `web/package-lock.json` 安装依赖。启动后访问：

| 服务 | 地址 |
| --- | --- |
| 网页 | http://127.0.0.1:5173 |
| API | http://127.0.0.1:8765 |
| API 文档 | http://127.0.0.1:8765/docs |

两个服务默认监听 `0.0.0.0`，同一局域网可通过 `http://本机IP:5173` 访问。前端通过同源 `/api` 代理连接后端。项目没有用户登录与权限隔离，适合本机或受信任局域网，**不要直接暴露到公网**。

按 `Ctrl+C` 停止服务。再次运行 `./start.sh` 会重启本项目的服务及任务子进程，可能中断正在运行或排队的任务；已保存数据保留。端口被其他项目占用时，脚本会停止启动，不结束其他项目进程。

拉取依赖变更后可手动同步：

```sh
uv sync --frozen
npm --prefix web ci
```

### 使用 Docker Compose

安装 Docker Engine / Docker Desktop 和 Docker Compose v2+，在仓库根目录运行：

```sh
docker compose up -d --build --wait
```

访问 **http://127.0.0.1:8080**。镜像构建使用锁定依赖，前端编译为静态资源，由 FastAPI 与 API 一起提供；只运行一个 Python 容器，无需容器内 Nginx。运行镜像不包含 Node.js、uv 或依赖下载缓存。镜像名固定为 `pullback-lab:latest`，可通过 `PULLBACK_IMAGE_TAG` 修改标签；不再随 Compose 项目名变化。构建阶段仅保留 JavaScript 引擎针对当前平台实际加载的动态库，排除 NumPy/Pandas 的上游自测目录，并执行引擎自检。新浪解码脚本及原许可保存在 `backend/vendor/`，无需安装完整 AKShare 及其接口依赖。首次构建需要下载基础镜像及依赖。

```sh
docker compose logs -f --tail=100  # 查看日志
docker compose down              # 停止并移除容器，保留数据卷
```

可复制 `.env.example` 为 `.env` 后调整端口、并发和可选 Token；Compose 自动读取 `.env`。默认仅绑定本机；如需受信任局域网访问，可设置 `PULLBACK_BIND_ADDRESS=0.0.0.0`。应用仍只接受 localhost/IP 形式的访问主机，不支持直接用自定义域名访问。

服务器已有 Nginx 时，将所有请求代理到 `http://127.0.0.1:8080` 即可；无需另行部署前端文件。HTTP/IP 访问示例（保留原始 Host 和端口，供同源校验使用）：

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 300s;
}
```

当前应用的主机校验只允许 localhost/IP；自定义域名及 HTTPS 终止代理还需另行配置应用的可信主机、来源与代理边界，此示例不表示已支持这些部署方式。

容器数据保存在项目的 `lab-data` 命名卷中（通常为 `pullback-lab_lab-data`），与本机 `data/` 独立，首次启动是空库。**不要使用 `docker compose down -v`，它会删除数据卷。** 不要扩容 backend 或增加 Uvicorn worker；任务并发使用上述环境变量调整。

备份、恢复和迁移本机数据前先停止服务，复制整个目录。以下示例把容器数据备份到新的 `backup/` 目录：

```sh
docker compose stop
mkdir -p backup
docker compose cp backend:/app/data/. ./backup/
docker compose start
```

迁入本机数据或恢复备份时，先执行 `docker compose create` 创建容器与卷，再在容器停止状态下执行 `docker compose cp ./data/. backend:/app/data/`（恢复备份时把 `./data/.` 换成备份目录）。复制后修正属主，再启动：

```sh
docker compose run --rm --no-deps --user root backend chown -R 10001:10001 /app/data
docker compose up -d --wait
```

恢复应使用空数据卷，避免把两份 SQLite 数据及 WAL 文件混合；保留旧卷作为回退。导入历史整包可运行 `docker compose exec backend python scripts/import_bulk.py sh sz bj`。

### 第一次研究

1. 点击左上角股票按钮，按代码、名称或拼音首字母搜索。
2. 打开「参数设置」，选择策略、全部／自定义日期范围、资金与费用。
3. 点击「一键研究」，等待四个步骤完成。首次下载和公告核验可能较慢。
4. 切换策略，查看 K 线、净值、回撤与交易明细。点击 B/S 查看成交价格、数量、费用和说明。
5. 在「研究工具」中查看数据质量、历史记录、参数寻优或股票池研究。只想验证当前参数时，使用「仅按当前参数回测」。

修改参数不会自动改变旧回测。历史结果绑定原始快照与参数；更新行情后需要重新运行，才会生成新结果。关闭进度弹窗不会终止任务，终止操作需使用对应按钮。

## 策略与成交模型

### 趋势回调（SMA）

使用短、中、长均线判断趋势与回踩，收盘确认反弹后，在下一市场交易日尝试开盘买入；收盘跌破中期均线后尝试卖出。可选沪深300趋势过滤，均线、斜率和回调观察周期可配置。

### Martin Luk 回调（日线量化版）

使用 EMA9/21/50、21/63/126 日涨幅、成交额、EMA21／锚定均价／前高支撑、信号日低点止损、风险仓位和 3R／5R 分批止盈。它是**明确命名的日线近似版本**，不包含原方法中的主观形态判断、盘中决策与分钟级执行。

具体条件与实现见 [`backend/strategies.py`](backend/strategies.py)。两种策略使用独立账户，不共享资金。

### 共同记账与执行规则

- 收盘产生信号，下一交易日尝试成交；无杠杆，不模拟真实委托队列。
- 保留停牌、T+1、股份尚未上市、开盘涨停买入／跌停卖出、资金不足和策略风控约束。
- 买单失败后取消，收盘信号重新满足才再次产生买单；卖单失败保留待执行状态。
- 默认滑点为每侧 **5 bps（0.05%）**。仅滑点越界时，将模拟成交价限制在「当日高低价与涨跌停价格范围的交集」内，并记录“滑点受行情边界限制”。**这利用日线价格范围建立成交假设，不证明盘中存在可执行订单。**
- 默认初始资金 10 万元，佣金万三、最低 5 元；引擎按成交日期处理过户费、印花税及差别化红利税。具体口径见 [`backend/engine.py`](backend/engine.py)。
- 登记日确权、除息日确认应收、支付日现金到账；送转区分权益、到账与可交易时间。分红不自动加仓。
- 期末不强制平仓；账户资产包含持仓市值与应收，尚未触发的潜在红利税单独展示。
- 主板、创业板、科创板按板块及历史日期使用对应涨跌幅和买卖数量规则，见 [`backend/trading_rules.py`](backend/trading_rules.py)。未覆盖的交易规则不能直接套用普通股票模型。

策略使用模拟日期已生效、已核验的公司行动调整历史指标；不会拿当前整段前复权行情直接代替历史决策输入。撮合和记账使用原始价格，图表复权只影响展示，不重复计入分红。

### 寻优与短历史适配

寻优在有限离散网格中按累计收益评选，固定数据版本、实际日期范围与费用条件；相同条件可复用结果。快速计算的优胜参数会用完整回测引擎复核。

- SMA 预热：`max(慢均线, 中均线 + 斜率周期, 中均线 + 回调周期 - 1, 2) - 1` 条有效日线。
- Martin 预热：`max(126, 锚点窗口)` 条有效日线。
- 寻优至少保留 **20 个有效回测交易日**，仅搜索历史足够支持的候选组合。
- 策略分别判断可运行性；数据不足时可跳过 Martin，而继续满足条件的 SMA。跳过不会清除用户勾选偏好。
- 适配与跳过原因会展示；公司行动核验、行情质量门槛不会取消。

20 日是可运行门槛，不是统计可靠性保证。寻优结果属于样本内研究，尚未自动执行滚动样本外验证；修改成交规则或数据后，旧参数不再代表新条件下的最优参数。

## 数据质量与来源

行情来自腾讯、新浪等公开接口，备用补数路径包括东方财富、BaoStock 和可选 Tushare。巨潮资讯实施公告用于核验公司行动与停复牌证据。若已导入通达信历史整包，同步优先读取整包，再补缺口和最新行情并交叉核验。

- 校验日期、OHLC、成交量、缺失交易日、跨源冲突、异常跳变、公司行动与指标预热。
- 未知缺口不当作停牌，不插值生成 K 线；有明确证据的停牌仅用于估值延续，不产生虚拟成交。
- 默认允许在修复失败后选择可用的完整连续历史区间，重新预热并明确标注实际日期；不跨缺口拼接收益。
- 北京时间 **15:00** 后才允许纳入当天日线。上游未发布时，只使用已返回且校验通过的数据。
- ETF、北交所支持搜索与行情缓存核验，**尚不承诺完整交易模拟**。ST、退市及其他未覆盖规则可能阻止正式回测。

### 对比指数自动更新

图表支持上证指数、创业板指等指数对比。打开行情图、返回页面和更新个股快照后自动检查，页面可见时每 **5 分钟**检查一次；后端按指数合并请求并缓存已校验结果。页面关闭后，不存在独立的全天候指数更新任务。

更新失败时保留已校验行情并标明截止日期。某日缺数据会显示“该日期暂无数据”，不使用上一日冒充当天。指数数据源发布延迟时，自动检查也无法提前获得新数据。

### 可选历史整包与批量缓存

服务安装完成后，可导入通达信历史行情底库：

```sh
.venv/bin/python scripts/import_bulk.py sh sz bj
```

整包可能占用较多磁盘，只提供行情，不替代公告及公司行动核验。按需使用，不是首次启动的必需步骤。

在 API 服务运行时执行批量缓存（不进行参数寻优）：

```sh
.venv/bin/python scripts/cache_batch.py sample100 --wait
.venv/bin/python scripts/cache_batch.py status <batch_id>
.venv/bin/python scripts/cache_batch.py pause <batch_id>
.venv/bin/python scripts/cache_batch.py resume <batch_id> --wait
.venv/bin/python scripts/cache_batch.py retry <batch_id> --wait
```

批次保存冻结样本与截止日期，重启后保持暂停，恢复跳过已完成成员。`complete` 表示当前核验通过，`review` 表示已缓存但有待核验项，`failed` 表示请求失败或无日线。

## 图表与收益口径

- 研究完成或打开历史结果后，行情图按该次配置范围展示完整行情；预热、已回测和未覆盖区域有明确区分。
- 「策略区间收益率」来自**策略账户资产变化**，不是股票涨跌幅。以区间前一交易日账户资产（或初始资金）为起点，包含持仓浮盈亏与已计费用、税费。
- 所选范围超出回测覆盖时，仅统计已有账户数据并提示“部分覆盖”；完全无覆盖时不编造收益。净值与回撤保持日频。
- K 线可滚轮缩放、拖动平移；净值／回撤使用 Ctrl＋滚轮。手机可横向滑动及双指缩放，也可使用按钮。
- 点击图表后，左右键移动光标，上下键或 `+`／`-` 缩放，`Home`／`End` 跳转两端。日期定位遇休市日时定位到下一已有交易日。
- 月／年 K 按已有交易日聚合，显示覆盖查看范围的周期；不补造周期内缺失行情。X 轴首尾完整显示年月日，中间标签按空间省略。
- B/S 保持垂直连接并上下避让；密集时可从汇总入口查看。月／年 K 按方向合并成交笔数。
- 百分比与股价完整显示，不使用 `k` 缩写；手机长数值自适应字体。其他大数按数量级使用 `k / M / B / T / P / E`。

## 股票池研究

成员记录包含加入／移出有效期，追溯加入需标为回顾性研究。可比较策略基线、结构止损与风险定仓、池内相对强度三组方案，并查看 MAE/MFE、年度分段和逐笔诊断。

每只股票是独立资金账户，**不是共享资金的投资组合回测**。历史成员回填无法消除事后选股或幸存者偏差；任一有效成员缺少当日必要数据时，不默默丢弃该成员继续排名。

| 环境变量 | 默认值 | 用途 |


环境变量需在启动进程中设置；启动脚本不自动读取 `.env`。不要把 Token 写入代码或提交到 Git。API 使用单进程调度与数据目录独占锁，**不要通过 Uvicorn 多 worker 增加并发**。

## 开发与 API

前端：React 19、TypeScript、Vite、ECharts。后端：FastAPI、SQLite、Python 日频事件引擎。

```text
backend/          API、行情与证据、策略、撮合、寻优和任务调度
scripts/          开发服务、历史整包导入、批量缓存命令
web/src/          研究界面、图表和共享组件
web/public/       网站图标及设计提案
start.sh          本地启动入口
uv.lock           Python 依赖锁文件
```

最小静态检查：

```sh
npm --prefix web run check
.venv/bin/python -m compileall -q backend scripts
```

静态检查不替代真实行情、浏览器和回测验证。修改撮合或会计规则时，应固定快照与参数重跑，并核对逐笔成交及寻优／完整引擎一致性。仓库不附带本机行情库或被忽略的临时验证脚本。

常用接口（完整请求结构见运行后的 `/docs`）：

| 接口 | 用途 |
| --- | --- |
| `GET /api/stocks?q=...` | 搜索股票 |
| `GET /api/overview?symbol=...` | 数据概况、参数与活跃任务 |

## 常见问题

**为什么同步成功，但不能回测？** 行情已保存不等于资料完整。缺口、送转实施公告、交易规则或预热不足都可能阻止研究；查看质量报告和实际区间说明。

**为什么图表有白色区域，收益显示部分覆盖？** 有行情不代表有该次策略账户数据。白色区域不计入本次策略收益；需要按目标范围重新回测，且仍须满足校验条件。

**为什么仍有未成交记录？** 滑点边界已按明确假设处理，但停牌、涨跌停、T+1、资金不足、止损距离等真实约束仍可能拒单。

**为什么看到收益很高？** 可能来自单股长周期或样本内寻优。请同时查看回撤、交易次数、实际区间和买入持有基准，不把研究结果当作收益承诺。

**为什么下一交易日没有建议？** 最新行情、交易日历或公司行动尚未核验时会暂停建议。信号只读取本地快照，不读取真实账户，也不保证下一开盘成交。
