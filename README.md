# 回调研究室

本机运行的 A 股日线回测工具。支持按代码、名称和拼音首字母选择 A 股，默认思源电气（002028.SZ），以沪深300作为可选趋势过滤。React + TypeScript + Vite + ECharts 前端，FastAPI 后端，SQLite 本地存储。

## 启动

需要 Python 3.11+、uv 和 Node.js 20.19+（或22.12+）。

```sh
cd /Users/xidahuang/code/pullback-lab
./start.sh
```

打开 http://127.0.0.1:5173 。后端为 http://127.0.0.1:8765 ，接口文档为 `/docs`。两个服务默认监听 `0.0.0.0`，局域网设备可通过 `http://本机局域网IP:5173` 访问；前端通过同源 `/api` 代理请求后端。支持 IP 地址和 localhost 访问，写入请求保留同源校验。终端按 Ctrl+C 停止。首次运行安装锁文件中的依赖；本次已安装。更新依赖后可执行 `uv sync --frozen` 和 `npm --prefix web ci`。

使用顺序：点击顶部股票名称选择标的 → 同步数据 → 查看数据质量 → 在“回测设置”弹窗保存参数 → 运行回测 → 查看交易/权益流水/每日资产 → 导出CSV。刷新恢复当前标的及其最新回测，保存的设置按标的保存在浏览器本地；关闭或取消弹窗丢弃草稿。修改参数不会自动运行。同步后再次运行默认使用最新快照；选中历史记录时使用该记录的原快照。

## 默认策略与会计口径

- 近十年，初始10万元，满仓进出，无杠杆、不加仓。买入数量按100股取整并预留费用。
- 收盘高于SMA200，SMA50高于10根有效日线前的值；最近5根日线曾回踩当日SMA20且收盘高于SMA50。
- 当日收盘重新高于SMA20和前一根最高价，产生买入信号；默认还要求沪深300高于SMA200。
- 空仓时下一市场交易日尝试开盘买入；收盘跌破SMA50则下一交易日尝试清仓。买单当日失效，卖单保留至可执行。
- 采用截至各日已生效的公司行动调整历史观察值，计算当日均线。成交、资产计价均使用未复权价格，不把未来分红用于历史信号。
- T+1；开盘涨停不买、开盘跌停不卖；停牌不成交。上下限价格按除权后的参考价计算。
- 滑点默认每侧5基点，价格四舍五入到0.01元；超出当日高低价或涨跌幅范围时不成交。
- 佣金默认万三、最低5元，佣金含经手费。过户费双边：2022-04-29前万分之0.2，之后万分之0.1。卖出印花税：2023-08-28前千分之一，之后万分之0.5。费用逐笔保留到分。
- 登记日确权、除息日确认应收、支付日现金到账。送转分别处理权益、到账和可交易时间；分红不自动加仓。
- 红利税根据自然月/自然年持有期计算（不含卖出交割当天，周年日卖出仍属于一年以内），在卖出时扣计，期间持仓显示潜在税额。使用登记日持仓批次，清仓时逐批结算。2016年资本公积转增的税务属性已按实施公告核验。
- 期末不强制平仓，期末资产包含持仓与应收，不扣尚未触发的潜在红利税。已平仓胜率按完整买卖周期、费用及分红后的盈亏计算。
- 买入持有基准在区间首个可执行交易日建仓，使用相同资金、仓位、费用及公司行动规则。
- 首版回测开始日期支持2016年起。配股、未核实送转、无法确定的零碎股分配、异常行情均停止回测，不近似填平。

税费依据：[差别化红利税](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)、[自然年月与先进先出](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n812151/n812386/c1082457/content.html)、[2023年印花税减半](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)。

## 数据与可追溯性

腾讯原始日线为主，新浪为补数、备用及交叉核验来源；新浪交易日历确定应有日期。AKShare只复用其成熟的新浪压缩数据解码器，不使用会填充缺失行情的表格处理路径。

新浪分红表与巨潮资讯实施公告核对每股金额、登记日、除息日、支付日；非零送转必须额外核对到账、可交易日和税务属性。公告PDF及响应原文保存为gzip、SHA-256寻址。往年分段行情缓存30日，当年行情、备用行情、日历和公告查询缓存6小时，公告PDF长期缓存。同一收盘截止区间已同步时直接复用快照；同步弹窗的“强制重查全部来源”绕过缓存。超时20秒，最多3次请求、退避重试。公开接口变化或限流会在页面呈现，已有有效数据保持可用。

`data/lab.sqlite` 保存不可变完整数据快照、质量报告、任务和回测；`data/raw/` 保存原始响应。快照内容变化生成新版本，相同语义数据不因报价响应时间戳变化而新建版本。每次回测绑定快照、参数、引擎版本和结果校验和，断网可再次回测。备份时停止服务后复制整个 `data/`；不要只复制运行中的sqlite主文件。`data/`、依赖、`work/`均不进入Git。

校验包含日期重复、缺失交易日、空值、OHLC关系、非正价格、成交量、异常跳变、两源价格差异、公司行动和指标预热。休市不会报缺失；未知缺失会尝试查询巨潮复牌公告，只有同时取得明确停牌日和复牌日才标记为已确认停牌；没有证据时保持阻断，也不插值。已确认停牌只能估值延用上一价格，不能生成交易记录。区间预热默认至少250根有效日线，超长参数相应增加。

两个已发现的沪深300历史差异通过 `backend/adjudications.py` 的精确条件校正，原值、新值和证据进入快照，不采用通用“备用源永远正确”的规则：

- 2015-03-27：腾讯最低价高于其开盘、收盘，选择OHLC合法且收盘一致的新浪记录。
- 2016-01-04：熔断日腾讯收盘3470.41与新浪3469.066不同，新浪收盘与[全景网当日收盘报道](https://www.p5w.net/stock/news/mszd/201601/t20160105_1316225.htm)3469.07一致。保留该更正提示。

## API

- `GET /api/overview`：覆盖范围、数据版本、默认参数、运行中任务。
- `POST /api/sync`：手动同步，返回任务ID。
- `GET /api/tasks/{id}`：任务进度、错误、结果ID。
- `GET /api/quality?snapshot_id=...`、`GET /api/bars?snapshot_id=...`：指定快照的校验/行情。
- `POST /api/backtests`：参数见 `/docs`；校验失败HTTP 422，未同步HTTP 409，任务互斥HTTP 409。
- `GET /api/backtests`、`GET /api/backtests/{id}`：历史与结果。
- `GET /api/backtests/{id}/export?book=strategy&kind=trades`：导出；book支持strategy/benchmark，kind支持trades/ledger/curve/rejected。

## 验证与边界

本次以2016-10-09至2026-10-09为默认区间，取得2015年起共2857根思源电气日线和12次实施分红记录。默认参数实际回测：策略总收益165.72%、年化10.27%、最大回撤41.40%、40笔成交、20次平仓、胜率30%；相同口径买入持有总收益1017.62%、最大回撤55.57%。结果不表示策略优于持有，不做参数寻优。

临时验证脚本保留在被Git忽略的 `work/verify.py`，用 `uv run python -m work.verify` 可复查35项关键断言，覆盖离线、可复现、未来数据隔离、数据缺口、订单限制、费用、公司行动及税率边界。`npm --prefix web run check`用于TypeScript检查。未执行完整生产build。

本工具为本机研究用途，不连接券商。日线无法验证开盘排队成交、真实市场冲击、盘中止损或券商精确清算；采用明确的保守成交假设。免费行情与公告不能保证持续可用或绝对正确。新增公司行动无法核实会阻止回测，不能通过关闭大盘过滤绕过个股数据问题。仅凭思源电气的历史结果不能判断全市场有效性。

## 多标的与缓存

- `GET /api/stocks?q=平安`：代码、名称、拼音首字母模糊搜索，返回最多30条。巨潮公开A股目录缓存7日，失败时回退已有目录。
- overview、bars、quality、backtests 列表支持 `symbol=002028.SZ` 查询参数。
- 同步请求体为 `{ "symbol": "002028.SZ", "force": false }`；回测参数包含 `symbol`，股票与快照不匹配会被拒绝。
- 历史快照与回测按股票隔离；旧格式数据兼容归属思源电气。沪深300、同URL公告共享请求缓存，切换标的不删除本地数据。
- 上市日期用于排除上市前缺口。正式成交模型目前限普通沪深主板；创业板、科创板、北交所及存在风险警示变更的股票可搜索和保存行情，但会明确阻止正式回测，不能套用10%涨跌停和100股规则。尚未实现全部A股交易规则。
- 平安银行实际保存2857根日线及15次公司行动。2016-01-04来源冲突及2015/2016送转未核实，十年回测被阻止；2018年起的区间用于验证第二标的回测与保存，不视为十年验证通过。

## 图表周期与均线

行情图支持日K、月K、年K；上涨K线为红色、下跌为绿色（收盘与开盘比较），成交标记为红色B、绿色S。月/年K按已有交易日聚合开、高、低、收，首尾可能是不完整周期，悬停显示实际覆盖日期和全部成交。默认展示最近120根日K、60根月K或全部年K，滑块可查看完整范围。

“均线设置”弹窗支持 MA5/10/20/30/60/120/200/250，保存至浏览器本地。图表MA按当前周期未复权收盘价计算，数据不足不绘制；仅影响看图，不替换策略使用的逐日公司行动调整均线，也不会切换回测执行周期。净值和回撤保持原回测的日频数据。

### 图表工作区操作

行情、净值、回撤共用日期区间并联动十字光标。支持近1月、近3月、近半年、近1年、全部、前后翻页和回到最新；切换月/年K时将查看范围对齐到已覆盖的K线周期。净值和回撤仍使用日频数据，不做周期抽样。行情与指标读数固定在图表上方，同周期成交可展开查看。

- 拖动图表平移；Ctrl＋滚轮缩放，普通滚轮滚动页面。
- 点击图表后：左右方向键移动光标，上下方向键或＋／−缩放，Home／End移动到最早／最新区间。
- “日期定位”跳转并显示该日期附近行情，非交易日定位至下一已有交易日，超出范围会提示。
- “放大查看”打开联动工作区，Escape退出；放大期间仍可调整均线和定位日期。

## 行情缺口自动修复

回测前遇到缺失行情或零成交量，自动按缺失年份重查腾讯行情，再用新浪补数、交叉核验。仍缺失的股票日期会查询巨潮停复牌公告，支持分别从停牌与复牌公告提取明确日期；核对证券代码、复牌日实际成交以及区间内没有正常成交后，才能标记为已确认停牌。预期日期、歧义、价格冲突继续阻断，绝不插值生成K线。

页面提供“尝试自动修复”、进度和可展开的公告证据。相同快照6小时内复用尝试结果，手动重试可重新请求。修复创建新快照，已有回测与旧快照不变；资料不完整、公司行动未核验等问题仍按原规则阻止回测。刷新或断网可读取已保存的修复记录。

接口：`POST /api/repair` 接收回测参数（含 symbol、snapshot_id），返回任务ID；`?force=true` 手动重试。`GET /api/quality` 包含最近修复报告。修复任务完成仅表示检查完成，不代表全部数据校验通过。

## 下一交易日信号

页面根据最新本地快照与已保存策略参数自动计算空仓／持仓两种条件信号，可手动重新计算。与回测共用指标函数；回测起止日期及历史快照选择不限制最新信号。展示依据日期、触发条件及质量阻断原因。重新计算只读取本地缓存，要更新行情请先同步。未核验下一市场交易日日期时不猜测日期；本地数据较旧时标记为历史条件信号。信号不读取真实账户，不代表下一开盘必然成交。接口为 `POST /api/signals/latest`，请求体使用回测参数。

## 完整区间兜底

默认启用，可在回测设置关闭。自动修复后仍存在有明确日期的行情或公司行动问题时，排除最后一个问题日期及之前的数据，仅以其后的完整数据重新预热，至少250根有效日线后才开始回测。原始缓存与旧结果不删除。结果保留原请求起点、排除边界、预热起点和实际交易起点；策略与买入持有使用同一区间。不明日期、标的或交易规则错误、范围越界以及剩余预热不足不会兜底放行。保存的参数包含 data_after，重复运行仍从相同边界计算。历史公司行动仍未核实，不视作被修复。

## 股票池与策略研究

顶部“股票池与研究”进入独立弹窗。可新建多个池，复用代码／名称／拼音搜索添加成员；缓存按股票复用，“同步池内数据”逐股同步，不强制重抓历史。移出保留成员记录，以移出日为不再有效的第一天；已有研究绑定当时成员快照，不受后续修改影响。加入默认为上海日期当天，过去日期须显式选择“回顾性历史成员”。这只能诚实标记事后构建的股票池，不能消除幸存者偏差；数据也使用本次保存的历史修订快照，并非拥有逐日的历史数据版本。

一次研究固定参数比较三组独立账户：原策略基线、结构止损＋风险定仓、风险管理＋池内相对强度。原策略不修改。结构止损取信号日及此前N根有效K线最低价，持仓期间仅因公司行动调整，不上移追踪；收盘跌破后下一市场交易日尝试开盘卖出，保留T+1、停牌、涨跌停和原模型的价格范围约束。单笔风险预算默认可用现金的0.5%（策略不加仓，开仓时空仓）；按实际模拟开盘价至止损的距离计算100股整数仓位，预留计划双边费用，目标仓位仍为上限。预算不含未来红利税与跳空损失，绝不保证最大亏损被锁住。买入日开盘已跌破止损则取消买入。

相对强度使用默认63根有效个股日线，除权除息仅调整截至观察日已生效的事件。公式为 (1+个股调整后区间涨幅)/(1+沪深300同起止日涨幅)-1，不是RSI。成员按当日有效期确定，在同期相对表现大于0且排名前N时取得开仓资格，随后还必须满足原策略买入条件。任何有效成员当日缺少行情／预热／核验，整个池该日暂停选股，结果列出缺失成员，不自动丢弃。移出股票池不强制卖出已有持仓。

每只股票为独立资金账户，三组对照使用该股同一起止日期和费用，**不是共享资金、多持仓、统一仓位限制下的组合回测**。兜底可能令不同股票起点不同，表中明确标注。年度结果是连续账户按年分段，不是重新初始化的年度独立实验；可保持参数固定，更改日期重复研究，结果均保存。没有参数寻优或宣称样本外有效。

逐笔诊断包含信号条件、进出场日期、初始止损、计划价差风险、MAE/MFE、税费后完整交易盈亏、退出原因和再入场时间／价格。MAE/MFE为公司行动调整后的价格浮动，不含税费；开盘卖出日不读取之后的高低价。仍持仓交易盈亏留空。研究结果、逐股快照ID、成员有效期和配置保存在SQLite，刷新可恢复，可导出诊断CSV。

API：`GET/POST /api/pools`，`POST /api/pools/{id}/members`，`POST /api/pools/{id}/members/{member}/remove`，`POST /api/pools/{id}/sync`，`POST/GET /api/pools/{id}/experiments`，`GET /api/experiments/{id}`，`GET /api/experiments/{id}/export`。同步与研究返回任务ID，沿用任务进度接口。

行情同步以北京时间 15:00 收市为界：收市前仅同步此前交易日，收市后可同步当日。当前年份行情及交易日历重新请求，历史行情继续复用缓存；上游尚未更新或数据校验失败时保留问题报告，后续同步会重新尝试，不将缺失视为停牌。

### 备用行情源

同步与自动修复发现缺口时，按缺失年份请求东方财富、BaoStock；若设置了 `TUSHARE_TOKEN` 环境变量，还会请求 Tushare。均使用未复权日线，成交量统一为股（东方财富/Tushare 手乘 100，BaoStock 股不换算）。不同来源 OHLC 差异超过 0.01 时记录冲突并阻断受影响回测，不投票覆盖。已保存行情和历史快照保留。

Tushare 是可选项：在启动服务的终端设置 `TUSHARE_TOKEN` 后运行 `./start.sh`，不要将 Token 写入仓库。股票 daily 和指数 index_daily 权限分别由账户决定；未配置时跳过，权限不足不影响其他来源。Token 不进入响应归档、快照或日志。

备用源有超时、三次退避重试；BaoStock 在独立子进程查询，单次最长 20 秒，避免其连接阻塞服务。原始 HTTP 响应或 BaoStock SDK 原始行响应压缩归档，来源报告随快照保存。免费接口仍可能延迟或不可用，最新日期以实际返回为准。


## 多策略回测与 Martin Luk 日线量化版

在“回测设置”勾选一个或多个策略，保存后点击“运行回测”。所有策略使用同一股票、快照、实际日期区间、初始资金与费用，独立记账。对比表包含收益、回撤、胜率、成交笔数与期末资产，净值图叠加各策略和买入持有；点击策略行切换指标、成交标记、交易明细和 CSV 导出。历史回测保留策略参数与结果，旧记录继续按 SMA 策略读取。

新增策略灵感来自[另一面介绍 Martin Luk 的推文串](https://x.com/OtherSideBJ/status/2109475443929972794)，是明确的日线量化近似，不是分钟原版复现：

- 使用 EMA9/21/50（首个有效收盘初始化，至少250根行情预热）。仅使用截至当天生效的公司行动调整历史价格；送转同时调整历史成交量。
- 最近21、63、126个有效交易日任一涨幅默认至少30%；近20日平均 `收盘价×成交股数` 默认至少2000万元。这是成交额近似值。
- 单股模式只筛绝对涨幅和流动性，不声称完成横向排名。可选择已有股票池，要求该股票在当天有效成员中，至少一个周期涨幅达到门槛并进入前30%（向上取整，同涨幅同名次）；保存股票池成员、各股快照和每日排名。任何成员数据校验不通过阻止整次回测；当日缺少候选分数不发入场信号。回顾性股票池存在事后选股偏差，池内排名不等于全市场排名。
- 趋势：收盘高于EMA50且EMA50向上。支撑候选为EMA21、日线近似AVWAP、此前窗口最高价。AVWAP锚点取此前63个有效交易日的最高价日期（同价取最近），用锚点起的典型价 `(高+低+收)/3` 按成交股数加权；并不使用未来峰值。
- 当天最低价接近任一支撑（默认1.5%容差），收盘重新站上该支撑、EMA9和前日最高价。信号日最低价作为初始止损，收盘止损距离不超过3%。不复现主观整理形态、首次回测判定、缺口支撑或分钟图触发。
- 下一市场交易日开盘重新检查止损距离：开盘跌破止损或距离大于3%则放弃。按可用现金的0.5%风险预算反推仓位，预留买卖双边费用，受共同仓位上限约束，100股取整。
- 收盘达到3R、5R时分别计划卖出初始仓位约1/3；按100股取整，每阶段至少100股且不超过剩余持股，小仓位可能提前清仓。同日直接达到5R合并两个阶段，只有实际成交后推进阶段。余仓收盘跌破EMA9或初始止损后计划全部卖出。均于下一市场交易日开盘尝试，延续T+1、停牌和涨跌停拒单逻辑。
- 分批卖出按FIFO分摊股份对应的历史分红税基，完全平仓才计一笔胜率样本；分红应收权益保留。送转调整止损、入场参考价、R和初始股数。
- 风险预算不是最大亏损保证：日线确认、跳空、跌停和T+1可导致实际损失超出预算。下一交易日信号仅提供新开仓条件及EMA9提示；结构止损、3R/5R需要真实持仓成本与已退出阶段，页面不会凭空推断。

原 SMA 策略保留原默认规则。沪深300过滤只作用于 SMA；Martin 日线版不额外加入该条件。

回测设置中的时间范围默认“全部”，自动使用所选快照预热后的最早可回测日期至缓存结束日期；支持“自定义区间”（包含起止日期）。同步后全部模式自动延伸，历史记录仍绑定原快照和实际区间。旧版未指定范围模式的 API 请求保持显式日期语义。

### 工业富联参数搜索

`python -m backend.optimize --workers 4` 复用本地快照、缓存指标并合并等价信号，使用原账户模型评估有限离散网格。网格范围见 `backend/optimize.py`，不是对连续参数全空间的穷举。资金、费用和交易约束固定；Martin 的 EMA 和 3R/5R 规则固定。

本次快照 `40165ccf208974906847`，区间 2019-06-20 至 2026-10-12，SMA 5,240 组、Martin 37,800 组，共 43,040 组，合并后 8,667 次账户计算，约 22 秒。按累计收益排序，平局按较小回撤、较少成交数，再按参数序列排序；获胜组合经过原引擎完整复核。结果在 `data/optimizations/601138-grid-v1/report.json`，完整候选在同目录 `candidates.jsonl`。

SMA 收益从 30.69% 到 615.85%，最大回撤 43.47%；Martin 从 -0.13% 到 132.10%，最大回撤 25.05%。Martin 最优单笔风险为 5%，是收益优先的激进组合。以上属于单股样本内网格最优，未做样本外验证。

`backend/strategy_defaults.json` 保存股票专属默认值和来源；只影响工业富联。网页按配置版本一次性更新已保存的策略参数，保留资金、费用、时间范围和策略选择；此后手动调整仍会保留。

### 固定参数跨股票验证

运行 `.venv/bin/python -m backend.cross_stock --workers 3`，复用已缓存快照、为缺少数据的标的同步公开行情和公司行动。行情解码器在独立进程中运行，避免多线程初始化冲突；最多 3 个并发任务。每完成一只股票即保存检查点。

样本是运行前固定的 40 只跨行业主板股票，不是全 A 历史成分股。冻结工业富联的两组最优参数，不逐股调优；目标区间 2019-06-20 至 2026-10-12。工业富联不计入跨股统计，同区间、缩短区间和未通过数据校验的股票分别列出。每股独立 10 万元账户，不是组合回测，也不是未来时间上的样本外验证。报告存于 `data/cross-stock/industrial-defaults-v1/report.json` 和 `report.html`，包含快照 ID、参数、收益、基准和阻断原因。不会把工业富联默认参数写入其他股票的设置。

共同区间复测另外筛选至少一年有效数据的非调参标的，按数据覆盖取交集，重置资金后再跑一次，不依收益选择股票或日期。其结果位于报告的 `common_window` 和 `common/report.html`。

### 个股参数寻优与复用

策略回测区域提供「寻找最优参数」「应用已保存参数」「强制重新搜索」。同时搜索 SMA 和 Martin 日线版，按累计收益评选；使用当前股票、本地快照、时间范围、资金与费用。仅支持单股条件，股票池横向排名需先取消。质量不合格则阻止搜索，不覆盖此前结果。

正常搜索按快照、区间、资金费用、数据兜底设置和搜索/引擎代码版本匹配缓存；强制搜索跳过缓存。成功复核后将两组策略参数按股票保存到 SQLite，并激活为该股默认值。刷新、切换股票和服务重启后仍可复用；手工修改可通过「应用已保存参数」恢复。应用只覆盖策略参数，不修改资金、日期、费用或策略勾选。新数据快照会提示需要重搜。

`optimizations` 保留历次成功结果，`active_optimization` 指向每股当前版本；详细候选与报告在 `data/optimizations/<股票>/<任务ID>/`。失败不会切换当前版本。参数搜索属于有限网格的样本内优化，不保证跨股票或未来收益。

### 简洁研究界面

主屏保留累计收益、年化收益、最大回撤和当前图表；「更多指标」提供胜率、成交笔数、持仓占比、期末资产、基准收益、费用与红利税。「策略对比」打开完整比较与规则说明；「下一交易日信号」「个股寻优」「数据检查」各自进入独立面板。

净值、行情 K 线、回撤通过切换查看，共享日期区间，切换策略不会重置该区间；初始显示完整回测区间。K 线周期、日期定位、均线设置、缩放与放大收纳于「图表工具」。信号跟随当前查看策略。交易、资金权益、质量明细与历史回测保留在「交易明细与历史」弹窗。参数按策略分组展开。

### 指数 K 线

在「行情 K 线 → 行情标的」切换当前个股、上证指数、深证成指、创业板指、科创50、沪深300或中证500。指数使用新浪财经完整日线和现有六小时原始响应缓存，默认查看最近250个交易日，可切换全部历史、日/月/年K及均线。仅展示已完成交易日的真实点位，校验日期唯一性与OHLC合法性；加载失败明确报错并支持重试，不填充缺失日期。指数仅用于图表查看，不改变个股回测、资金曲线或成交记录。

### 自适应工作台

主界面按窗口宽高重新排布，不使用整页缩放：图表填充剩余高度，矮横屏改为左侧操作与指标、右侧图表。研究入口集中在顶栏「研究工具」，「交易明细与历史」在独立窗口打开；窄屏或矮窗口将 OHLC 和均线数值收纳到「行情详情」，图表工具集中到弹窗。图表本身保留可用高度；极小窗口及长明细允许必要的局部滚动，不通过禁止滚动裁切内容。行情和回测数据口径不变。

### B/S 成交标记与指数对比

个股 K 线默认同图叠加上证指数和创业板指实线，在「对比指数」中可更换或取消。指数收盘价按可见区间首个共同收盘日归一化到主图价格，右轴为相对涨跌幅；缩放会改变基准日。缺失日期断线、不填补，不将指数点位当作股价或策略收益。

回测买点为红 B 向上箭头、卖点为绿 S 向下箭头，圆点对应实际回测成交价。悬停显示成交摘要，点击显示价格、数量、金额、费用、税费及已有的策略原因/风险字段。月年 K 按方向合并标签并显示笔数；标签打开该组全部成交，圆点打开对应成交；压缩视图中距离过近的同方向成交点合并展示，避免误选遮挡的成交。标记监听图表逐帧渲染和缩放事件，随拖动平移、滚轮缩放、窗口变化实时重定位；支持键盘聚焦后 Enter 打开详情。

### 一键研究与终止

主按钮「一键研究」依次更新已收盘行情、补齐与校验、搜索个股网格最优参数、自动回测。沿用当前股票、时间范围、资金、费用和策略选择；相同快照及条件复用已保存寻优结果。结果按寻优使用的实际区间复算，数据兜底仍显式展示。原来的手动回测保留在「研究工具 → 仅按当前参数回测」。

步骤、加载进度、失败原因在独立弹窗中展示；关闭弹窗不停止后台任务，可通过「查看进度」重新打开，刷新后可恢复活跃任务。点击「终止任务」会停止该任务的独立进程组，包括并行寻优工作进程；已完成的数据快照与参数保留，未完成的回测不发布。校验未通过不会继续寻优或回测。

API：`POST /api/workflows` 接受回测参数；`GET /api/tasks/{id}` 返回四步骤进度；`POST /api/tasks/{id}/cancel` 终止一键任务。相同类型、股票资源及参数的活跃请求复用同一任务；同股票不同任务排队，不同股票默认最多并发 2 个。工作日志统一按日期保存。


### 并发、日志与重复启动

- 单个 API 进程内置任务调度，默认 `PULLBACK_TASK_CONCURRENCY=2`（1–4），排队上限 64。`PULLBACK_OPTIMIZER_WORKERS=2` 控制每个寻优任务的子进程数（1–4）。
- 相同请求复用活跃任务并返回 `reused: true`；不同参数的同股票任务按顺序执行。股票池研究/同步占用其成员股票资源，避免与个股任务同时改写数据。页面恢复的任务进度按股票筛选，可切换股票查看或启动另一任务。
- SQLite 事务登记任务与资源；数据目录独占锁拒绝第二个 API 调度进程，避免多 worker 启动误改运行状态。请勿使用 Uvicorn 多 worker；通过上述任务并发参数调节计算并行度。
- `./start.sh` 再次运行会自动停止并重启本仓库的前后端及任务子进程。会中断正在运行/排队的任务，已保存数据保留；重启后中断任务可重新发起。启动前核对进程工作目录和命令，其他程序占用端口时停止启动，不结束其他程序。并行执行启动脚本会串行完成重启。
- 日志为 `data/logs/app-YYYY-MM-DD.log`，以 Asia/Shanghai 日期分文件，保留当天及前 29 天；启动和跨日首次写日志时清理更早文件。旧 `workflow-logs` 目录中超期任务日志也会清理。
- 同步打印到启动控制台：记录服务启停、任务复用/排队/开始/结束、同步来源与年度进度、缓存命中、修复报告、请求参数、寻优结果、回测指标与成交统计、接口异常与堆栈；不打印正常轮询请求、逐候选参数或每次百分比变化。

### 历史证据修复与创业板

补数优先核验停复牌公告，再向现有行情源补取仍缺失的日期；明确停牌日不生成虚拟 K 线。实施公告支持分页，永久公告缓存可在强制刷新行情时复用。送转核验要求实际比例、到账日、上市日和现金税款证据；差异化分派的除权参考现金及参考股本比例与实际到账权益分开计算。修复解析版本更新后会重新核验旧失败记录。

普通创业板股票按日期采用涨跌幅规则：2020-08-24 前 10%，之后 20%；校验、成交约束和寻优共用规则。仍不支持 ST、退市等未覆盖规则。证据不足时沿用显式完整区间兜底；不会将未知缺口直接当成停牌，实际回测范围保留在结果中。
